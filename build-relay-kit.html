The Beat Relay

Build a real drum machine together — one person, one feature at a time — just by talking to an AI. No coding experience needed. Then take it home and keep building.

PART 1

Facilitator Guide

Everything you need to run the session and hand attendees something they keep.

Before the event (≈15 min, once)

  1. Use the hosted master copy so the microphone works. The Sampler needs the app to run as its own web page (not embedded). It's already live at chi-65.github.io/CTW-projects — open that link and you're ready to go. (Prefer your own copy? Drag drum-machine.html onto app.netlify.com/drop for an instant Netlify link — no account needed for a temporary one.)
  2. Test it on your own phone. Open the link, play a beat, then open the Sampler and record a sound. Tap “Allow” when the mic prompt appears.
  3. Make a QR code for the link (search “free QR code generator,” paste your link) and put it on a slide so the room can open the app instantly.
  4. Have the file ready to give out — email it, AirDrop it, or share the hosted link. Attendees need the file (or link) to keep building later.
  5. Pick relay groups of 6–8 people and print one copy of Part 2 per person.

How the relay works

Each person adds one feature by typing a single prompt, then passes the conversation to the next person. The magic to point out: the whole app lives in the conversation, so the next person picks up exactly where the last one left off. Nobody needs to understand the previous code — they just ask for the next thing.

Why this works: when you share the chat, you share the entire project — the AI can read everything built so far. Handing off the conversation is the collaboration.

The relay sequence — exact prompts

Green = works anywhere, every time. Purple = bonus; needs the hosted link (mic/sharing).

1The drum machineCore

Teaches: the grid, playback, tempo.

Build me a 16-step drum machine as a single web page with four rows — kick, snare, hi-hat, and clap. Each row is 16 tap buttons. Add a Play button and a tempo slider. Make all the sounds with the Web Audio API — no sound files.
2Preset beatsCore

Teaches: patterns, that music is just data.

Add three preset buttons — Boom Bap, Four on the Floor, and Trap Hats — that fill in the grid with a beat when tapped.
3Echo (delay)Core

Teaches: effects, sends, signal routing.

Add a delay/echo effect with a settings panel, and a send slider for each drum so I can choose how much of each one goes into the echo.
4Sync the echo to tempoCore

Teaches: rhythm math (beats vs. milliseconds).

Change the delay time from milliseconds to note values synced to the tempo, like 1/4, 1/8, and 1/16 notes.
5Filter you can drawCore

Teaches: automation — changing a control over time.

Add a low-pass/high-pass filter on the whole mix, with a lane I can draw on to set how the filter moves across the 16 steps, playing back in time with the beat.
6Swing & reverbCore

Teaches: feel and space.

Add a Swing slider for a shuffle feel, and a Reverb slider that adds room sound to the whole kit.
7More drumsCore

Teaches: extending the instrument.

Add two more drum sounds as new rows — an open hi-hat and a cowbell.
8Surprise MeCore

Teaches: generative randomness with rules.

Add a "Surprise Me" button that generates a random but musical beat — kicks on the beat, snares on the backbeat, hats filling in.
9Record your own soundBonus · hosted

Teaches: hardware & permissions — the real "ceiling."

Add a sampler that records a short sound from the microphone and adds it as a new track I can sequence, with a pitch slider.
10Share your beatBonus · hosted

Teaches: saving & sharing state.

Let me save and share my beat as a link that reopens the exact pattern when someone else clicks it.
Teaching moment for the room: steps 1–8 work for everyone, instantly. The bonus steps only get hard because they touch a microphone and sharing — that is, real hardware and permissions. The lesson: AI builds the instrument in seconds; where you run it decides what it's allowed to do.
PART 2

Take This Home

You built it — now keep it, and keep going. Everything here is free.

Play it anytime

Open the workshop link (or the QR code) on any phone or computer:

Your link: chi-65.github.io/CTW-projects

Running the app is 100% free and uses no AI credits — it plays entirely in your browser.

Keep building it — just by talking (easiest)

  1. Go to claude.ai and start a chat (a free account works).
  2. Attach the drum-machine file the facilitator gave you (or paste your link).
  3. Type what you want to add — for example:
Here's my drum machine. Add a piano keyboard I can play with the mouse or by tapping.

The file carries the whole app, so the AI can keep editing it. No coding — just ask.

Get a free GitHub account (to host & save your own copy)

  1. Go to github.com and click Sign up.
  2. Enter your email, pick a username and password.
  3. Verify your email (check your inbox for a code).
  4. Choose the Free plan — it's all you need.

GitHub is where developers store and share projects. Free accounts can host web pages for free.

Put your own copy online (free hosting)

Fastest — Netlify Drop (no coding):

  • Go to app.netlify.com/drop.
  • Drag your HTML file onto the page.
  • You instantly get a live link you can share. Sign in (free) to keep it forever.

With GitHub — GitHub Pages:

  • Make a new repository → upload your file, renamed index.html.
  • Open the repo's Settings → Pages.
  • Under "Build and deployment," pick Deploy from a branch → main → / (root) → Save.
  • Wait about a minute — your site appears at your-username.github.io/your-repo.
Remember: the microphone Sampler only works on a hosted page (a real link over https), not inside an app preview. Both options above give you that.
